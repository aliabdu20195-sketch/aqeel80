# 💼 نظام المحاسب — نظام محاسبة ومخزون يعمل بالكامل بدون إنترنت

نظام محاسبي جاهز للاستخدام لإدارة الأصناف والمبيعات والمشتريات والعملاء والموردين والمصروفات والتقارير، مبني بالكامل كملف HTML واحد، يعمل **بدون إنترنت** وبدون أي خادم أو قاعدة بيانات خارجية — كل البيانات محفوظة محلياً على جهاز المستخدم.

## ✨ المميزات

- 📊 **لوحة تحكم** تعرض مبيعات وأرباح اليوم والشهر، قيمة المخزون، وتنبيهات النقص في الأصناف.
- 📦 **إدارة الأصناف**: بحث، تصنيف، استيراد/تصدير CSV، حد أدنى لإعادة الطلب.
- 🧾 **فواتير بيع وشراء** مع تحديث تلقائي للمخزون وتكلفة الأصناف، وطباعة الفاتورة مباشرة.
- 🗂️ **سجل فواتير** قابل للفلترة والبحث، مع إمكانية الحذف والتراجع عن أثره على المخزون والأرصدة.
- 👥 **العملاء والموردون** مع متابعة الأرصدة المستحقة وتسديدها.
- 💸 **المصروفات** مصنّفة (إيجار، رواتب، كهرباء...) مع إجمالي تلقائي.
- 📈 **تقارير** لفترة مخصصة: المبيعات، الأرباح، الأصناف الأكثر مبيعاً، ملخص المخزون.
- 💾 **نسخ احتياطي واستعادة** بصيغة JSON، بالإضافة لإعدادات المؤسسة (الاسم، الهاتف، بادئة رقم الفاتورة).
- 📱 قابل للإضافة إلى الشاشة الرئيسية على الموبايل مثل تطبيق مستقل (PWA-ready).

## 🧱 التقنية المستخدمة

ملف HTML/CSS/JavaScript واحد بدون أي مكتبات خارجية أو اتصال بالإنترنت. تخزين البيانات عبر `localStorage` في متصفح الجهاز.

## 🚀 طريقة الاستخدام

1. حمّل ملف `نظام-المحاسب.html`.
2. افتحه مباشرة في أي متصفح (يعمل من الجهاز مباشرة بدون رفع على استضافة).
3. أو ارفعه على أي استضافة/GitHub Pages للوصول إليه من رابط.
4. أول تشغيل يُنشئ بيانات تجريبية (أصناف وعملاء وهمية) — يمكن حذفها والبدء من جديد من صفحة **الأصناف** و**النسخ الاحتياطي**.

## ⚠️ ملاحظات هامة

- البيانات محفوظة **محلياً في المتصفح فقط**. مسح بيانات المتصفح أو استخدام جهاز/متصفح مختلف يعني فقدان الوصول للبيانات، لذا يُنصح بأخذ نسخة احتياطية (صفحة "النسخ الاحتياطي") بشكل دوري.
- لا يوجد نظام تسجيل دخول أو صلاحيات مستخدمين — الملف مخصص للاستخدام الفردي أو على جهاز موثوق.
- يمكن استيراد/تصدير الأصناف بصيغة CSV لتسهيل النقل بين الأجهزة.
